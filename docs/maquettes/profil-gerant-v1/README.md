# Maquettes — profil gérant v1

À valider avant implémentation. Règles : `docs/contrats/profil-gerant-certification-v1.md`.

Ouvrir `index.html` dans un navigateur. Aucun service, compte, transfert de fichier ou dépendance n'est nécessaire.

- Quatre vues : profil gérant, soumission, fin de soumission et profil public.
- Deux onglets dans le profil : informations et documents.
- Le sélecteur de simulation permet de voir une identité manquante ou en attente, et la demande de publication alors bloquée.
- Le bouton d'envoi dirige vers une confirmation dans la liste des résidences.
- Le sélecteur du profil public permet de retirer la certification du gérant sans modifier les badges des résidences.
- Les fichiers sélectionnés restent sur l'appareil ; aucune requête d'envoi n'est effectuée.
- Les noms, offres et montants sont fictifs. Les images sont des illustrations de maquette.

Les simulations, la barre de navigation entre maquettes et les données fictives ne font pas partie de l'application.

Les captures du dossier `previews` sont produites à partir de ce fichier aux formats ordinateur et téléphone.
