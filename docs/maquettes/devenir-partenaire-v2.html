Nous vous accompagnons

Vos questions
avant de vous lancer.

Comprendre le fonctionnement avant de publier, c’est préparer une relation durable avec vos voyageurs.

Dois-je renvoyer mon identité pour chaque résidence ?

Vos pièces personnelles sont enregistrées dans votre profil gérant. Elles accompagnent vos résidences selon leur état de validation.

Le certificat de résidence est-il obligatoire ?

Non. Il complète votre identité pour obtenir le badge Gérant certifié. Il n’est pas une condition de publication.

Puis-je gérer plusieurs résidences ?

Oui. Votre espace permet de présenter et de suivre plusieurs résidences depuis le même compte gérant.

Puis-je enregistrer mes réservations téléphoniques ?

Oui. Enregistrez-les dans votre calendrier afin de mettre à jour les disponibilités de vos logements.
